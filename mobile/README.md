# Приложение Bron (React Native / Expo)

Одно приложение для Android, iOS и веба:

- **Клиент**: направления → заведения (поиск, «рядом со мной») → карточка заведения → мастер и услуга → дата и
  свободное время → заявка; «Мои записи» с отменой; профиль, язык, уведомления, удаление аккаунта.
- **Специалист** (переключение в профиле): заявки с таймером 10 минут, подтверждение и отказ, календарь по дням,
  ручная запись клиента и блокировка времени, услуги, недельный график с перерывом, выходные и отпуск, настройки записи;
  создание заведения или вступление в существующее; для владельца — данные, фото и сотрудники заведения.
- **Веб-панель главного админа** (открывается в браузере для аккаунта-админа): модерация заведений, заведения,
  пользователи, направления с полями анкеты, записи, статистика, настройки, журнал действий.

Языки интерфейса: узбекский и русский (веб-панель — на русском).

## Запуск

```bash
cd mobile
npm install
cp .env.example .env      # укажите адрес бэкенда
npx expo start            # Android/iOS через Expo Go или dev-сборку, w — веб
```

- Эмулятор Android: `EXPO_PUBLIC_API_URL=http://10.0.2.2:8000/api/v1`.
- Телефон в той же Wi-Fi сети: IP компьютера, например `http://192.168.1.10:8000/api/v1`, и добавьте этот адрес
  в `DJANGO_ALLOWED_HOSTS` бэкенда.
- Веб-панель: `npx expo start --web` или сборка `npm run export:web` (папка `dist/`); адрес сайта добавьте
  в `CORS_ALLOWED_ORIGINS` бэкенда.
- `EXPO_PUBLIC_DEV_LOGIN=1` показывает вход по номеру без Telegram — только для разработки.

Проверки: `npm run typecheck`.

## Пуш-уведомления

Приложение получает Expo push-токен и отправляет его на бэкенд (`PUSH_BACKEND=expo`). Для этого проект нужно
привязать к EAS (`npx eas-cli@latest init` — появится `extra.eas.projectId` в `app.json`) и собрать приложение
(`eas build`). В Expo Go и в браузере пуши не регистрируются.

## Сборка и публикация

```bash
npx eas-cli@latest build --platform android   # .aab для Google Play
npx eas-cli@latest build --platform ios       # для App Store (нужен аккаунт Apple Developer)
```

Идентификаторы `uz.bron.app` и название `Bron` — временные, поменяйте в `app.json`, когда будет утверждён бренд.

## Структура

| Папка | Что внутри |
| --- | --- |
| `src/app` | Экраны (Expo Router): `client/` — вкладки клиента, `pro/` — вкладки специалиста, `admin/` — веб-панель |
| `src/api` | Клиент API с автообновлением токена, типы ответов |
| `src/auth` | Контекст входа, режим клиент/специалист, регистрация пушей |
| `src/components` | Общие элементы интерфейса, карточка записи, профиль |
| `src/i18n` | Тексты на узбекском и русском |
